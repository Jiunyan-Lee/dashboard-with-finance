## 2. 資料模型與備份格式

匯出／匯入均使用整份狀態 JSON；陣列欄位即使只有一筆也必須維持陣列。

```js
{
  current: {
    month: 'YYYY-MM',
    entryDate: 'YYYY-MM-DD',
    salary: '50000',
    totalInvestment: '1000000',
    banks: [
      { name: '帳戶名稱', amount: '300000', initialAsset: true }
    ],
    holdings: [
      { account: '證券戶', name: '商品名稱', category: 'aggressive', amount: '200000' }
    ],
    brokerCash: [{ name: '證券戶名稱', amount: '50000' }],
    debts: [{ name: '債務名稱', amount: '100000' }]
  },
  snapshots: [/* 與 current 相同結構的月度資料卡 */],
  trades: [{ date: 'YYYY-MM-DD', name: '標的名稱', cost: '50000', proceeds: '55000' }]
}
```

證券分類代碼：

| 代碼 | 介面名稱 |
| --- | --- |
| `aggressive` | 積極型 |
| `conservative` | 保守型 |
| `leveraged` | 槓桿型 |
| `longBond` | 長債 |
| `shortBond` | 短債 |

注意事項：

- `banks`、`holdings`、`brokerCash`、`debts`、`snapshots`、`trades` 均必須是 JSON 陣列。
- 匯入程式目前用同一個錯誤訊息同時處理 JSON 解析與匯入後渲染錯誤；若顯示「無法讀取此備份檔案」，先檢查上述欄位型別。
- 專案不內附 JSON 測試或真實備份；回歸測試請自行建立匿名資料，`debts` 必須維持陣列格式。

## 3. 核心計算

### 資產與負債

- 股票資產 = 積極型 + 保守型 + 槓桿型
- 債券資產 = 長債 + 短債
- 現金 = 銀行現金 + 證券現金
- 總資產 = 股票資產 + 債券資產 + 現金
- 淨資產 = 總資產 − 債務
- 可支配金額 = 現金 − 債務
- 曝險金額 = 積極型 + 保守型 + 長債 + 短債 + 槓桿型 × 2
- 槓桿比例 = 曝險金額 ÷ 淨資產
- 債務比 = 債務 ÷ 總資產
- 淨債務比 = 債務 ÷ 淨資產

### 收入與花費

工作起點為最早已儲存資料卡月份；資料卡期間為起點至目前資料卡的含首尾月數。

- 累積薪水 = 起點至目前資料卡的薪水合計
- 平均月收入 = 累積薪水 ÷ 資料卡期間
- 初始資產 = **當月資料卡**中勾選 `initialAsset: true` 的銀行帳戶金額合計；當月未勾選任何帳戶時為 0
- 粗估累積花費 = 初始資產 + 累積薪水 − 本月總資產
- 粗估本月花費 = 本月粗估累積花費 − 前一個月粗估累積花費；無前一個月份資料時顯示「—」
- 粗估平均月花費 = 粗估累積花費 ÷ 資料卡期間
- 實際累積花費 = 初始資產 + 累積薪水 − 總投入金額 − 銀行現金
- 實際本月花費 = 本月實際累積花費 − 前一個月實際累積花費；無前一個月份資料時顯示「—」
- 實際平均月花費 = 實際累積花費 ÷ 資料卡期間

### 股票部位與交易

- 股票部位 = 股票 + 債券 + 證券現金
- 扣除質押後股票部位 = 股票部位 − 債務
- 已實現損益 = 賣出金額 − 買進金額
- 報酬率 = 已實現損益 ÷ 買進金額

交易損益正數採台股慣例紅字、淺紅底；負數採綠字、淺綠底。年度統計含年度、交易次數、買進金額、賣出金額、損益與報酬率。

## 4. 六個分頁

左側導覽順序與群組如下：

1. 總覽、月度資料卡、動態回顧
2. 分隔線後：每月資料填寫、賣出紀錄與損益
3. 分隔線後：使用說明

桌面側欄以水平分隔線區分群組；手機版側欄為水平可捲動導覽時，分隔線改為垂直線。
### 總覽

固定以最新已儲存資料卡顯示：

1. 資產總攬：總／淨資產、股票／債券／證券現金、總投入、占比、槓桿、債務、可支配金額。
2. 收入與花費：直接引用最新月度資料卡，依三列呈現「本月入帳薪水／累積薪水／平均月收入」、「粗估累積花費／粗估本月花費／粗估平均月花費」、「實際累積花費／實際本月花費／實際平均月花費」。
3. 資產配置：甜甜圈圖與右側可點擊圖例清單；圖例可各別開關。
4. 資產比例變化：股票、債券、現金占總資產比例，以及槓桿比例、淨債務比折線。
5. 資產與累積收入：股票、債券、證券現金、銀行現金堆疊直條；總資產、淨資產、累積薪水、總投入金額折線。
6. 累積收入與花費趨勢：粗估累積花費與實際累積花費。
7. 平均月收入與花費趨勢：粗估平均月花費與實際平均月花費。
8. 每月收入與花費趨勢：粗估本月花費與實際本月花費；顏色分別與同類型平均月花費一致。

總覽圖表共通行為：

- 月份序列只到「最新已儲存資料卡月份」，不延伸到電腦目前月份。
- 折線／柱狀圖圖例均為資料集開關。關閉資料時先消失、再調整 Y 軸；開啟資料時先調整 Y 軸、再顯示資料。
- Y 軸只以目前圖例開啟資料計算；左右雙軸同步。折線端點有安全留白與 clip 設定，避免圓點或最右資料被裁切。
- 資產比例圖的 Y 軸下限固定為 0%。上限僅以目前圖例開啟的折線計算：若最大值未超過 100%，依可見資料向上取 10% 級距動態縮放、且上限不超過 100%；任一折線超過 100% 時，解除 100% 上限，採最大值約 1.1 倍後向上取 10% 級距。
- 資產與累積收入圖最大值為可見資料最大值的 **1.05 倍**，再以 1、1.2、1.5、2、2.5、3、4、5、6、8、10 × 10 的次方選擇上界。
- 累積花費圖在 100 萬以下採 10 萬級距，超過後採百萬級距，並保留 1.2 倍上方空間。

### 每月資料填寫

包含月份、填寫日期、當月薪水、總投入金額、銀行帳戶、證券資產、證券戶現金與債務。

銀行帳戶每列有置中的「初始資產」勾選框。桌面版表單兩欄約 47%／53%，右側證券資產／債務欄略寬；手機版自動改為單欄。

標題右側上方為「查詢月份」，下方依序為「刪除此月份資料」、「清空目前資料」、「儲存月度資料」。查詢月份與儲存按鈕同寬（桌面版 115px）；選取月份後會立即載入該月完整資料，包含「資料月份」。

### 月度資料卡

可選月份檢視完整卡片，僅提供統計與明細展示。載入／刪除功能已移至「每月資料填寫」頁面的查詢月份控制項。卡片依序包含總覽統計、投資組合指標、收入與花費、月／年資產變化、年度統計、資產熱力圖與原始清單。收入與花費固定依 3／3／3 張卡片分成三列，並採與總覽統計相同的卡片尺寸與留白規則。總覽統計、投資組合指標、收入與花費、月／年資產變化、年度統計、資產熱力圖，以及資產清單（銀行帳戶／證券資產／證券戶現金／債務）皆為獨立視覺區塊。

月／年資產變化的年度比較週期採「第 N 年 2 月至第 N+1 年 1 月」，整段皆以第 N 年 1 月資料卡為基準；亦即 2 月至 12 月使用當年 1 月，1 月使用前一年 1 月。若基準月份資料卡不存在，相關年度比較顯示「—」。年度薪資統計仍採當年 1 月至所選月份累計。

年度統計採當年 1 月至所選月份的已儲存資料卡累計。刪除後會同步更新總覽、月度選單與動態回顧。

### 賣出紀錄與損益

可新增、編輯、刪除賣出紀錄；交易區域具局部捲軸。顯示已實現損益與年度交易統計。

### 動態回顧

此區塊目前維持既有行為，除非有明確需求，**不要為了調整總覽而修改此區塊**。

可選起訖月份，四個區塊各自有播放／暫停、速度、進度與目前月份：資產配置、資產比例變化、資產與累積收入、資產熱力圖。速度單位為月／秒，預設 1 月／秒。

- 資產配置維持完整圓環，比例平滑變化。
- 資產比例圖包含股票、債券、現金、槓桿比例與淨債務比；只動畫當前月份，前月份資料固定。Y 軸下限固定為 0%，依已播放且圖例開啟的資料動態調整：未超過 100% 時上限不超過 100%，超過 100% 時解除上限並保留約 10% 留白。
- 資產／收入圖只動畫當前月份，前月份資料固定；播放中 Y 軸依可見系列與已播放資料調整，左右軸同尺度。
- 播放時鎖定圖例，避免狀態衝突。
### 使用說明

提供不涉及資料寫入的程式內操作指南。桌面版布局為：

1. 第一列左右並排：「常用操作與提醒」與「查看成果」。
2. 第二列整列寬度：「填寫說明」，採圓點清單，涵蓋每月資料填寫與賣出紀錄輸入流程。
3. 第三列整列寬度：「資料說明」，列出輸入欄位、月度資料卡全部統計指標、資料來源與計算式。

「資料說明」中每個指標以「項目名稱：說明」或「項目名稱＝計算方式」呈現，不同項目換行；內文字級與「常用操作與提醒」一致（15px）。頁面提到的分頁、一般按鈕與欄位名稱以綠色粗體標示；「刪除此月份資料」和「清除所有資料」因屬危險操作，使用與實際按鈕相同的紅色粗體。

## 5. 資產熱力圖

資料來源為證券資產、銀行帳戶與證券戶現金。面積與金額成比例，同分類先分區、再在區內排列，讓相同分類聚集。

- 圖例固定列出七類，可各別開關。
- Tooltip 顯示順序：類別、項目名稱、金額、占顯示資產百分比。
- Tooltip 為 body 下的 fixed 元素，游標離開熱力圖即隱藏。
- 外框保持矩形；必須保留以下 CSS：

```css
.heatmap-floating-tooltip[hidden]{display:none!important}
.heatmap-cell .heatmap-tooltip{display:none!important}
```

## 7. 隱私與 RWD

「隱藏金額」啟動後，所有金額、金額座標軸、tooltip、清單與輸入金額以 `****` 顯示；金額輸入欄變為唯讀。百分比、月份與名稱不遮罩。

版面已有手機 RWD，且總覽、月度資料卡、動態回顧、每月資料填寫、賣出紀錄與損益、使用說明共用一致的手機頁面骨架：頁首與內容邊距一致、主要內容單欄呈現、側欄改為水平可捲動導覽。

每月資料填寫在手機版以置中標題與單欄控制項呈現；證券資產資料列保留單筆一列的橫向滑動輸入方式。賣出紀錄在手機版使用可橫向捲動的固定欄寬表格，日期與一般輸入欄同為 44px 高，避免日期欄位重疊或被裁切。已實現損益資料卡於桌面與手機版均靠左對齊。

總覽的大尺寸圖表已可在手機顯示，但多資料系列圖仍需持續以實機確認可讀性；目前尚未導入圖表橫向滑動或拆分圖表的調整。

## 8. 維護注意事項

- `compute`
- `renderDashboard`
- `renderCharts`
- `renderAllocation`
- `incomeExpenseMetricsV13`
- `averageExpenseTrendV39`
- `cumulativeExpenseTrendV41`

## 10. 雲端化方向

尚未實作。既定架構為：

```text
Netlify + Supabase Auth + Supabase PostgreSQL + Row Level Security
```

親友以 Email／Password 登入；資料表以 `user_id = auth.uid()` 的 RLS 做隔離。單機 JSON 應透過登入後的驗證、預覽與覆蓋／略過匯入流程寫入資料庫，不應直接作為雲端資料庫檔案。不可將 Supabase `service_role` 金鑰放在前端。

## 11. 安全提醒

專案可能含真實財務資料。不得將真實 JSON 備份、截圖、帳密或財務資料提交到 Git、公開連結或外部服務。開發、上線與重構一律先使用匿名測試資料驗證。

## 次年 1 月年度結算制（Version 107）

年度資料卡與總覽年度系列圖表統一採次年 1 月結算：

- 第 N 年年度期初為 N/01，正式期末為 N+1/01；資產總覽、投資組合、年度成長、年度績效及大分類熱力圖均採期末資料。
- 年度粗估／實際花費彙整 N/02～N+1/01 的月度差額，共 12 個月份。
- 「本月入帳薪水」仍依欄位原意彙整 N/01～N/12，不納入 N+1/01，避免重複計入下一年度薪水。
- 尚未取得 N+1/01 時，期末暫採該年度目前最新月度資料，並標示「尚未結算」；取得 N+1/01 後自動改為「已結算」。
- 次年 1 月同時是前一年度期末與新年度期初，但只會依上述區間納入各年度流量一次。
