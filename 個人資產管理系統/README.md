# 個人資產管理系統

一個純前端、以瀏覽器本機儲存資料的個人財務管理工具。可記錄每月資產、收入、債務與賣出交易，並以總覽、月度資料卡、動態回顧與趨勢圖呈現財務變化。

## 快速開始

1. 以瀏覽器直接開啟 `index.html`，不需要安裝套件、啟動伺服器或建立帳號。
2. 前往程式內的「每月資料填寫」，填寫資料並按「儲存月度資料」。
3. 透過「月度資料卡」檢視單月資料、「年度資料卡」檢視年度結算資料，並在「總覽」與「動態回顧」查看趨勢。
4. 定期使用右上角「匯出備份」下載 JSON 備份檔。

> 資料只儲存於目前瀏覽器的 Local Storage；更換瀏覽器、清除網站資料或使用不同裝置時，不會自動同步。請在清除資料或大幅調整前先匯出備份。

## 主要分頁

- **總覽**：最新月度資料卡的資產統計、收入與花費，以及資產／花費趨勢圖。
- **月度資料卡**：按月份查看已儲存的完整資產、收入與花費統計。
- **年度資料卡**：按年度查看次年 1 月結算的資產、收入、花費、績效與大分類熱力圖。
- **動態回顧**：以時間軸播放資產配置、比例、資產收入與熱力圖的變化。
- **每月資料填寫**：建立、載入、更新或刪除月度資料卡。
- **賣出紀錄與損益**：管理已賣出交易與年度交易統計。
- **使用說明**：程式內的日常使用指南與指標說明。

## 備份與隱私

- 匯出檔名格式為 `finance-dashboard-YYYY-MM-DD.json`。
- 匯入時請使用由本系統匯出的 JSON；測試時請先自行建立不含真實財務資料的匿名備份。
- 「清除所有資料」會清除該瀏覽器儲存的財務資料與隱私設定，且無法復原。
- 專案可能含敏感財務資料；請勿將真實備份檔、截圖或帳密上傳至公開位置。

## 開發注意事項

本專案不需要建置流程；圖表透過 Chart.js CDN 載入，因此首次開啟時需要可連網載入圖表函式庫。`app.js` 有歷史同名函式覆寫，修改前請先閱讀 [目前版本說明.md](目前版本說明.md) 的「交接速查」與回歸測試清單。
