USER GUIDE

使用說明

依照每月資料卡記錄資產、收入、債務與交易，系統會自動整理統計與圖表。

常用操作與提醒

  • 在「每月資料填寫」選取月份後，可用「刪除此月份資料」移除整張資料卡。
  • 右上角可匯出／匯入 JSON 備份；匯入前請確認檔案來源與月份是否重複。
  • 「清除所有資料」會刪除本瀏覽器儲存的所有財務資料，操作前請先匯出備份。
  • 「隱藏金額」會將畫面上的金額及座標軸金額顯示為 ****，適合在他人面前查看圖表。
  • 點選左上角「◒ 個人資產管理系統」，可快速回到目前頁面的最上方。

資料僅儲存於此瀏覽器；清除瀏覽器網站資料或更換裝置前，請務必先匯出 JSON 備份。

查看成果

  • 總覽：固定顯示最新月份的資產總攬、收入與花費、資產配置，以及年度與月度系列趨勢圖。
  • 月度資料卡：選取任一月份，查看當月統計、收入與花費、詳細指標、月／年成長、年度統計、熱力圖與資產明細。
  • 年度資料卡：選取年份，以當年 1 月至次年 1 月查看年度資產狀況、收入與花費、年度資產變化及七大分類資產熱力圖；未有次年 1 月時顯示暫估結果。
  • 動態回顧：選擇起訖月份後，可播放資產配置、比例、收入與熱力圖的逐月變化；每張圖的圖例皆可作為顯示開關。
  • 賣出紀錄與損益：查看已實現損益、淨損益與依賣出日期彙整的年度交易統計。

填寫說明

  • 前往「每月資料填寫」，填寫資料月份、填寫日期、當月入帳薪水與總投入金額。
  • 填入銀行帳戶、證券資產、證券戶現金與債務。銀行帳戶中可勾選「初始資產」，作為部分花費計算的基準。
  • 按下「儲存月度資料」建立或更新該月份資料卡。修改既有月份時，以右上方「查詢月份」選取資料，內容會自動載入。
  • 前往「賣出紀錄與損益」，逐筆填入賣出日期、商品／標的、買進金額與賣出金額；系統自動計算已實現損益與報酬率，並彙整年度統計。

資料說明

填入的資產資料

  • 銀行帳戶：帳戶名稱與餘額；勾選初始資產的金額會作為該月份收入與花費計算的初始資產基準。
  • 證券資產：券商、商品名稱、分類與現值。積極型／保守型／槓桿型歸入股票；長債／短債歸入債券。
  • 證券戶現金：各證券戶尚未投入的現金餘額。
    債務：債務種類與餘額。

總覽統計

  • 總資產＝股票資產＋債券資產＋銀行現金＋證券現金；
    淨資產＝總資產－債務金額。
  • 股票資產金額＝積極型＋保守型＋槓桿型；
    債券資產金額＝長債＋短債；
    證券現金金額＝所有證券戶現金合計。
  • 總投入金額為該月手動填入、截至當月的累積投入本金。
  • 股票／債券／現金占比＝各該金額÷總資產；現金＝銀行現金＋證券現金。
  • 曝險金額＝非槓桿型證券資產合計＋槓桿型證券資產合計×2；
    槓桿比例＝曝險金額÷淨資產。
  • 債務金額＝所有債務餘額合計；
    債務比＝債務金額÷總資產；
    淨債務比＝債務金額÷淨資產；
    可支配金額＝現金總額－債務金額。

收入與花費

  • 累積薪水＝最早資料卡至當月的薪水合計；
    資料卡期間為最早月份至當月（含）的月數；
    平均月收入＝累積薪水÷資料卡期間。
  • 初始資產＝當月資料卡中勾選「初始資產」的銀行帳戶餘額合計；當月未勾選時為 0。
  • 粗估累積花費＝初始資產＋累積薪水－本月總資產；
    粗估平均月花費＝粗估累積花費÷資料卡期間。
  • 銀行現金＝所有銀行帳戶餘額合計；
    實際累積花費＝初始資產＋累積薪水－總投入金額－銀行現金；
    實際平均月花費＝實際累積花費÷資料卡期間。
  • 粗估本月花費＝本月粗估累積花費－前一個月粗估累積花費；
    實際本月花費＝本月實際累積花費－前一個月實際累積花費。若無前一個月份資料則顯示「—」。

投資組合指標

  • 股債比＝股票資產占（股票資產＋債券資產）的比例：債券資產占同一合計的比例。
  • 積極型／保守型／槓桿型／長債／短債占比＝各分類現值÷總資產；卡片同時顯示各分類金額。

月／年資產變化

  • 總資產月成長＝本月總資產－前一張資料卡總資產；
    總資產年成長＝本月總資產－年度基準月份總資產。年度基準月份：2 月至 12 月使用當年 1 月；1 月使用前一年 1 月。
  • 扣除質押後總資產成長＝本月淨資產－年度基準月份淨資產；
    年度績效＝（本月淨資產－年度基準月份淨資產）÷年度基準月份淨資產。
  • 股票部位＝股票資產＋債券資產＋證券現金；
    扣除質押後股票部位＝股票部位－債務金額。
  • 股票部位月成長＝本月股票部位－前一張資料卡股票部位。年度比較基準＝本月總投入金額＋年度基準月份的股票部位總成長；據此計算股票部位年成長、扣除質押後股票部位成長與股票部位年度績效（後兩者均使用扣債務股票部位）。
  • 股票部位總成長＝股票部位－總投入金額；
    扣除質押後股票部位總成長＝扣除質押後股票部位－總投入金額；
    股票部位總績效＝扣除質押後股票部位總成長÷總投入金額。

年度資料卡

  • 年度統計區間：第 N 年年度資料以 N/01 為期初、N+1/01 為正式期末，用來反映第 N 年完整年度的資產結果。
  • 已結算：已有 N+1/01 月度資料卡，年度資產、投資組合、成長績效與熱力圖採該月份資料。
  • 尚未結算：尚未取得 N+1/01 時，暫時採用第 N 年目前最新月度資料，新增 N+1/01 後會自動轉為已結算。
  • 年度入帳薪水＝N/01～N/12 的本月入帳薪水合計；N+1/01 的薪水歸入下一年度，不會重複計入。
  • 年度平均月薪＝年度入帳薪水÷第 N 年已有薪水資料的月份數。
  • 年度粗估花費＝N/02～N+1/01 的粗估本月花費合計。
  • 年度實際花費＝N/02～N+1/01 的實際本月花費合計。
  • 總資產年成長＝年度期末總資產－N/01 總資產。
  • 扣除質押後總資產成長＝年度期末淨資產－N/01 淨資產。
  • 年度績效＝（年度期末淨資產－N/01 淨資產）÷N/01 淨資產。
  • 股票部位年成長：沿用月度資料卡的年度比較基準，以年度期末股票部位比較「期末總投入金額＋N/01 股票部位總成長」。
  • 扣除質押後股票部位成長：以年度期末扣除債務後股票部位比較相同年度基準。
  • 股票部位年度績效＝扣除質押後股票部位年成長÷年度股票部位比較基準。
  • 股票部位總成長＝年度期末股票部位－年度期末總投入金額。
  • 扣除質押後股票部位總成長＝年度期末股票部位－年度期末債務－年度期末總投入金額。
  • 股票部位總績效＝扣除質押後股票部位總成長÷年度期末總投入金額。
  • 年度資產熱力圖：採年度期末資料，彙整為證券資產｜積極型、保守型、槓桿型、長債、短債、銀行帳戶｜銀行現金及證券資產｜證券戶現金七類；面積依目前開啟的分類金額比例計算；圖例可點選開關，尺寸與月度資料卡一致。金額為 0 的分類只保留圖例，不顯示個別帳戶或商品。
  • 次年 1 月資料：同時是前一年度期末與新年度期初；資產快照可同時作為兩個年度的邊界，但薪水與花費依上述區間各計入一次。

月度資料卡的年度統計與資產熱力圖

  • 年度累計薪資＝當年 1 月至當月已儲存資料卡的薪水合計；
    年度平均薪資＝年度累計薪資÷該區間已儲存資料卡筆數。
  • 資產熱力圖以每筆證券資產、銀行帳戶與證券戶現金的金額決定區塊面積；提示框會顯示類別、項目名稱、金額與占總資產比例。
